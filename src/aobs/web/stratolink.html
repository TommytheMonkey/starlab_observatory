Provision a tracker

1. Get the provisioning tool on the computer the tracker plugs into

The observatory cannot reach your Mac's USB ports, so a small Python tool does the USB part and reports back here.

Download stratolink_provision.py 
python3 -m venv ~/.stratolink && ~/.stratolink/bin/pip install "meshtastic>=2.7"
~/.stratolink/bin/python stratolink_provision.py detect

2. Name it and choose a profile

3. Run it with the tracker plugged in

~/.stratolink/bin/python stratolink_provision.py provision <bundle>.json

It reads the node ID, hardware and firmware from the board, refuses other hardware and old firmware (pointing you to the official web flasher), shows each change, applies, reboots, reads every setting back, waits for GPS and sends a test message. It never copies keys or identities.

Register or edit a ground station

Add a ground station

1. Firmware

Supported: SenseCAP M2 US915 (board sensecap,wm7628n) only. Flash from the gateway's own web page (System → Backup/Flash) or with gateway flash below, which checks the board and region first and refuses anything else. Flashing resets it to 192.168.168.1 on its LAN port with no root password: set one and connect it to the network.

2. Let the observatory log in (you type the password into ssh, once)

cd ~/starlab-dev && .venv/bin/python -m aobs.stratolink gateway trust <gateway-ip>

3. Check it

.venv/bin/python -m aobs.stratolink gateway inspect <gateway-ip>

4. Deploy the radio config and service, name and place it

.venv/bin/python -m aobs.stratolink gateway deploy <gateway-ip> --name "Ridge" --lat 35.90 --lon -81.20 --alt 400 --dry-run
.venv/bin/python -m aobs.stratolink gateway deploy <gateway-ip> --name "Ridge" --lat 35.90 --lon -81.20 --alt 400

It backs up the gateway, writes /root/stratolink.json with the gateway's own EUI, installs the procd service, disables the stock LoRaWAN services, starts, registers the station, waits for its keepalive and then for an RF packet: send a test message from a tracker. Rollback: gateway rollback <ip>.
